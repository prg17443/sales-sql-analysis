# 📂 Dataset Description

This project uses a transactional sales dataset containing order-level records.

## 📊 Table: Orders

The dataset includes the following columns:

- Order_ID – Unique identifier for each order
- Order_Date – Date of purchase
- Customer_ID – Unique customer identifier
- Customer_Name – Name of the customer
- Region – Geographic sales region
- Category – Product category
- Sub_Category – Product sub-category
- Product_ID – Unique product identifier
- Product_Name – Product name
- Sales – Revenue generated
- Profit – Profit earned from sale
- Quantity – Units sold
- Discount – Discount applied
- Ship_Mode – Shipping method used

## 📌 Dataset Purpose

The dataset is used to:
- Analyze revenue and profitability
- Evaluate regional performance
- Identify customer retention patterns
- Detect seasonal trends
- Study discount impact on margins
